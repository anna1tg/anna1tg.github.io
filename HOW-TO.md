# Як опублікувати сайт і додавати статті

## 1. Публікація (один раз)

1. Увійдіть на https://github.com під акаунтом **anna1tg**.
2. Натисніть **+** → **New repository**.
   - Repository name: **`anna1tg.github.io`** (саме так).
   - Public → **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file**.
4. Перетягніть **весь вміст** папки `anna-aleshko-site` (не саму папку, а файли й папки всередині) → **Commit changes**.
   - Порада: у Finder натисніть Cmd+Shift+. — щоб бачити приховані файли; їх теж можна перетягнути, але вони не обов'язкові.
5. **Settings** → **Pages** → Source: *Deploy from a branch*, Branch: **main**, папка **/(root)** → Save.
6. Через 1–3 хвилини сайт буде за адресою **https://anna1tg.github.io**

## 2. Щоб Google знайшов сайт

1. Відкрийте https://search.google.com/search-console → **Add property** → **URL prefix** → вставте адресу сайту.
2. Підтвердження: оберіть **HTML tag**, скопіюйте рядок `<meta name="google-site-verification" content="...">`.
   Відкрийте `_config.yml` і додайте в кінці:
   ```
   webmaster_verifications:
     google: ТУТ_КОД_З_CONTENT
   ```
   Commit → зачекайте 2 хв → натисніть **Verify**.
3. У Search Console → **Sitemaps** → введіть `sitemap.xml` → Submit.

Далі Google сам знаходитиме нові статті (зазвичай від кількох днів до кількох тижнів).

## 3. Як додати нову статтю

Блог двомовний:
- **англійські** статті → папка **`_posts`** → адреса `/blog/назва/`
- **українські** статті → папка **`uk/_posts`** → адреса `/uk/blog/назва/`

Щоб зв'язати переклади (з'явиться перемикач EN/UA і Google показуватиме потрібну мову), додайте в шапку **обох** версій однаковий рядок, наприклад `ref: ai-ads-guide`.

1. У репозиторії відкрийте потрібну папку (`_posts` або `uk/_posts`) → **Add file** → **Create new file**.
2. Назва файлу строго у форматі: **`РРРР-ММ-ДД-назва-англійською.md`**
   наприклад `2026-10-01-ai-ads-for-small-brands.md`
   (назва після дати стане адресою статті — пишіть латиницею, через дефіс, ключові слова).
3. Вставте шаблон і напишіть текст:

```
---
title: "Заголовок статті"
description: "Одне-два речення про статтю — це побачать у Google."
ref: nazva-dlia-zviazku-perekladiv
---

Перший абзац.

## Підзаголовок

Текст. **Жирний**, *курсив*, [посилання](https://example.com).

- пункт списку
- ще пункт

![Опис картинки](/images/назва-картинки.jpg)
```

4. **Commit changes** → через 1–2 хвилини стаття з'явиться на сайті й на головній.

### Картинки
Папка **`images`** → **Add file** → **Upload files** → завантажте JPG/WebP (бажано до 500 КБ).
У статті: `![Опис](/images/файл.jpg)`. Обкладинка статті — додайте у шапку рядок `image: /images/файл.jpg`.

### Поради для Google
- Одна стаття — одна тема й ключова фраза (напр. «AI ads for small brands»), вона має бути в заголовку, `description` і першому абзаці.
- Використовуйте підзаголовки `##`, пишіть від 600 слів.
- Пишіть «опис картинки» — Google його читає.
- Посилайтесь на сайт з Instagram і TikTok (в описі профілю).

### Редагувати чи видалити статтю
Відкрийте файл у `_posts` → ✏️ редагувати або ⋯ → Delete file.

Приклади вже є:
- `uk/_posts/2026-06-10-yak-otrymuvaty-hlyboki-vidpovidi-vid-shi.md` і `_posts/2026-06-10-why-ai-gives-generic-answers.md` — одна стаття двома мовами (з вашого допису в Instagram);
- `_posts/2026-09-16-what-an-ai-creative-director-does.md` — зразок, відредагуйте або видаліть.

### Своя кнопка внизу статті (необов'язково)
```
cta_text: "Безкоштовний гайд"
cta_button: "Отримати в Instagram"
cta_url: https://www.instagram.com/p/.../
```

## 4. Як змінити ціни чи послуги

Усі послуги й ціни лежать в одному файлі: **`_data/rates.yml`** (доплати — у `_data/rates_extras.yml`).
Відкрийте файл на GitHub → ✏️ → змініть потрібний рядок → **Commit changes**. Обидві сторінки (EN і UA) оновляться самі.

- Усі ціни в доларах. `en_price` — ціна на англійській сторінці (`/rates/`, пишеться `from $350`), `uk_price` — на українській (`/uk/rates/`, пишеться `від $350`).
- Щоб додати послугу, скопіюйте блок від `- en:` до `uk_price:` включно, зберігаючи відступи (пробіли, не Tab).
- `highlight: true` — виділяє послугу рамкою (як «Пакет»).

## 5. Оплата на сайті

GitHub Pages — це статичний сайт, він не вміє сам приймати гроші. Тому оплата працює через посилання зовнішнього сервісу: клієнт натискає кнопку на сторінці цін і потрапляє на захищену сторінку оплати.

Кнопки з'являться самі, щойно ви вставите посилання у файл **`_config.yml`**:

```
payment:
  intl: "https://buy.stripe.com/ваше-посилання"   # для іноземних клієнтів
  ua: "https://send.monobank.ua/jar/ваше"         # для клієнтів з України
```

Порожні лапки `""` — кнопка не показується.

Де взяти посилання:
- **Payoneer** (для клієнтів з-за кордону): у кабінеті Payoneer → **Get Paid / Request a Payment**. Підійде також ваше посилання `payoneer.me/...`.
- **monobank «Банка»** (для клієнтів з України): додаток monobank → **+ → Банка** → назва «Послуги» → відкрийте банку → **Поділитися** → скопіюйте посилання `send.monobank.ua/jar/...`.
- **LiqPay, Fondy, WayForPay** — коли буде активований ФОП і потрібні рахунки та закриваючі документи. Посилання вставляється в той самий рядок `ua:`, а назву кнопки міняють у `_data/i18n.yml` (`pay_ua`).

Реквізити карток і паролі в сайт не вписуються ніколи: на сторінці лише посилання на сервіс оплати.

Текст під кнопками змінюється там же, у `payment: note_en` і `note_uk`.
