# Як опублікувати сайт і додавати статті

## 1. Публікація (один раз)

1. Увійдіть на https://github.com під акаунтом **anna1tg**.
2. Натисніть **+** → **New repository**.
   - Repository name: **`anna1tg.github.io`** (саме так).
   - Public → **Create repository**.
3. На сторінці репозиторію натисніть **uploading an existing file**.
4. Перетягніть **весь вміст** папки `anna-aleshko-site` (не саму папку, а файли й папки всередині) → **Commit changes**.
   - Порада: у Finder натисніть Cmd+Shift+. — щоб бачити приховані файли; їх теж можна перетягнути, але вони не обов'язкові.
5. **Settings** → **Pages** → Source: *Deploy from a branch*, Branch: **main**, папка **/(root)** → Save.
6. Через 1–3 хвилини сайт буде за адресою **https://anna1tg.github.io**

## 2. Щоб Google знайшов сайт

1. Відкрийте https://search.google.com/search-console → **Add property** → **URL prefix** → вставте адресу сайту.
2. Підтвердження: оберіть **HTML tag**, скопіюйте рядок `<meta name="google-site-verification" content="...">`.
   Відкрийте `_config.yml` і додайте в кінці:
   ```
   webmaster_verifications:
     google: ТУТ_КОД_З_CONTENT
   ```
   Commit → зачекайте 2 хв → натисніть **Verify**.
3. У Search Console → **Sitemaps** → введіть `sitemap.xml` → Submit.

Далі Google сам знаходитиме нові статті (зазвичай від кількох днів до кількох тижнів).

## 3. Як додати нову статтю

1. У репозиторії відкрийте папку **`_posts`** → **Add file** → **Create new file**.
2. Назва файлу строго у форматі: **`РРРР-ММ-ДД-назва-англійською.md`**
   наприклад `2026-10-01-ai-ads-for-small-brands.md`
   (назва після дати стане адресою статті — пишіть латиницею, через дефіс, ключові слова).
3. Вставте шаблон і напишіть текст:

```
---
title: "Заголовок статті"
description: "Одне-два речення про статтю — це побачать у Google."
date: 2026-10-01
---

Перший абзац.

## Підзаголовок

Текст. **Жирний**, *курсив*, [посилання](https://example.com).

- пункт списку
- ще пункт

![Опис картинки](/images/назва-картинки.jpg)
```

4. **Commit changes** → через 1–2 хвилини стаття з'явиться на сайті й на головній.

### Картинки
Папка **`images`** → **Add file** → **Upload files** → завантажте JPG/WebP (бажано до 500 КБ).
У статті: `![Опис](/images/файл.jpg)`. Обкладинка статті — додайте у шапку рядок `image: /images/файл.jpg`.

### Поради для Google
- Одна стаття — одна тема й ключова фраза (напр. «AI ads for small brands»), вона має бути в заголовку, `description` і першому абзаці.
- Використовуйте підзаголовки `##`, пишіть від 600 слів.
- Пишіть «опис картинки» — Google його читає.
- Посилайтесь на сайт з Instagram і TikTok (в описі профілю).

### Редагувати чи видалити статтю
Відкрийте файл у `_posts` → ✏️ редагувати або ⋯ → Delete file.

Приклад статті вже є: `_posts/2026-09-16-what-an-ai-creative-director-does.md` — відредагуйте або видаліть її.
